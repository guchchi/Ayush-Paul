# Phase 7 Checklist — Deliver Work & Get Clients 2 & 3

- [ ] Deliver work on or before deadline
- [ ] Communicate proactively during the project (no silent stretches)
- [ ] Send a results recap to client after delivery
- [ ] Request a testimonial (written quote)
- [ ] Request a LinkedIn recommendation
- [ ] Ask for 3 referrals with context ("Know any founders launching a site?")
- [ ] Follow up with referrals using warm context
- [ ] If you get referrals, repeat Phase 5 & 6 with warm leads
- [ ] Update your client counter: 1/3 → 2/3 → 3/3
- [ ] Celebrate — you got your first 3 paying clients!
