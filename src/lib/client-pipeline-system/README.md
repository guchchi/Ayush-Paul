# Module 5: Client Pipeline System

## Overview
Module 5 tracks active opportunities, pipeline stages, proposal status, and deal progression.

## State Management
- Store: `useClientPipelineSystemStore`
- Route: `/workspace/client-pipeline`
- Context Integration: Receives portfolio assets from Module 4 to feed outbound proposals.

- Proposal Readiness Checklist
- Pipeline Conversion Analytics
