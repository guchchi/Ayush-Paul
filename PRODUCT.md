# GitGlow Product Context (PRODUCT.md)

## 1. Product Purpose
GitGlow is an official GitHub achievement simulator, profile growth engine, and guided developer audit tool. It helps computer science students and working developers unlock official GitHub achievement trophies (Pull Shark, Quickdraw, YOLO, Pair Extraordinaire, Galaxy Brain) through verified, automated sandbox git operations.

## 2. Register
**product** (Developer Tool / Profile Growth Utility). Design serves the utility, clarity, and credibility of the user.

## 3. Users & Target Audience
- **Primary:** 1st and 2nd-year computer science students (Tier 2/3 colleges in India and globally) who have created a GitHub account but have an empty achievements tab and don't know how to unlock badges legally.
- **Broad Core:** Working developers, freelancers, and bootcamp graduates seeking profile credibility for recruiters.
- **Device Reality:** 60%+ access via budget Android smartphones, often opening links through college WhatsApp, Telegram, or LinkedIn webviews.

## 4. Brand Voice & Tone
- **Tone:** Technical mentor, honest, clear, celebrating small wins.
- **Plain English:** No alien corporate jargon or condescending lectures.
- **Hinglish Touch:** Light, natural conversational microcopy in celebration tooltips (e.g. *"Bas 2 min me ready"*).

## 5. Strategic Principles & Moats
- **The Core Moat:** Automated 1-click sandbox execution engine. Competitors are static blog posts; GitGlow is an interactive live tool.
- **Anti-Cheat Policy:** Zero fake activity, zero fake green squares, zero bot stars. Real GitHub API git workflows only.
- **Zero Login Friction:** Anyone can scan any public username without logging in. OAuth is requested strictly at the moment of execution.
- **Claim Own Account Only:** Public scanning is open, but claiming write actions is strictly locked to `scannedUsername === loggedInUser`.

## 6. Anti-References (What We Are NOT)
- We are NOT a SaaS marketing template with soft pastel blobs or generic purple gradients.
- We are NOT a fake star-trading or commit-faking service.
- We are NOT an over-engineered complex dashboard with 50 tabs. One primary goal: audit username and claim missing trophies.
