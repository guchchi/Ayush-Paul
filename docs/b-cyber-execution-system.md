## 1. Product Philosophy & Value Proposition

### The Problem
Traditional coaching institutes (JEE coaching, college courses) operate on a one-size-fits-all model focused purely on rote examination metrics (PCM). When premier institutions like IIT Kanpur introduce innovative, practice-oriented degrees like the **Bachelor of Cybersecurity (B.Cyber.)**, students are left in complete darkness:
- Zero past papers or standardized coaching syllabi exist.
- Misinformation thrives regarding JEE Main cutoff ranks vs the actual evaluation criteria.
- Complete beginners (like Arjun from a tier-3 college, or Shorya balancing Class 12 JEE) either get overwhelmed by 10,000 generic internet tutorials or waste time without building verifiable proof-of-work.

## 2. FREE TIER: "Know the Truth. Know Your Options."

### 2.1 The B.Cyber Ground Reality Report
- **The Core Premise**: Jointly offered by IIT Kanpur & IIT Madras through WSAIS (Wadhwani School of AI and Intelligent Systems) & C3iHub.
- **The Screening Truth**:
  - JEE Main is an eligibility checkpoint, not the rank decider. Top rankers aren't guaranteed seats; students with modest JEE scores but demonstrable practical aptitude get shortlisted.
  - The 2027 Horizon: Introduction of a dedicated Aptitude & Logical Reasoning assessment combined with the practical hackathon.
- **The File Submission Reality**:
  - The application portal asks for "Evidence of Prior Work / Technical Experience".
  - What 90% submit (and get ignored): Flat resume, random certificates of completion, generic school projects.
  - What works: Verifiable artifacts, live GitHub repositories, documented CTF problem-solving, and creative demonstration (e.g. an authentic 2-minute screen recording walkthrough).
- **The On-Campus Hackathon Reality**:
  - In-person assessment inside IIT Kanpur computer labs.
  - Jeopardy-style CTF structure across Linux, Networking, Web, and Cryptography.
  - The fatal mistake: Spending 90 minutes on a single 50-point hard rabbit hole while leaving high-yield 300 points on the table.

### 2.2 The Open Master Resource Directory
Zero teaching required; direct routes to the highest-signal free platforms:
1. **Command Line & Linux Foundations**: OverTheWire (Bandit levels 1–15).
2. **Networking & Packet Analysis**: Wireshark sample captures + basic TCP/IP handshake inspection.
3. **Web Vulnerability Fundamentals**: PortSwigger Web Security Academy (SQLi & XSS apprentices).
4. **CTF Practice & Mindset**: PicoCTF & TryHackMe beginner rooms.
5. **C & Low-Level Foundations**: CS50x / Beej’s Guide to Network Programming (for students with C interest like Arjun).

## 3. PAID TIER: "The 8-Stage Personal Execution System"

### Stage 1: The Intake Engine
Captures the user's specific context across 4 dimensions:
1. **Academic Profile**:
   - `class_12_jee`: Currently in 11th/12th/Dropper targeting JEE Main + B.Cyber.
   - `college_year_1`: 1st year B.Tech/B.Sc feeling unsatisfied with college placement prospects.
   - `college_year_2_3`: 2nd/3rd year looking for immediate IIT internships (e.g. C3iHub Jan/Summer) + B.Cyber 2027 entry.
2. **Technical Baseline**:
   - `total_zero`: Never opened a terminal, no programming background.
   - `basic_c_math`: Knows basic C programming, strong mathematical curiosity (like Arjun).
   - `python_scripter`: Knows basic Python syntax, done school coding.
   - `web_dabbler`: Built basic websites, knows HTML/JS.
3. **Weekly Time Budget**:
   - `constrained_5h`: 3–5 hrs/week (Heavy JEE or College exam load; weekend focus only).
   - `moderate_10h`: 8–10 hrs/week (Balanced rhythm).
   - `dedicated_15h`: 15+ hrs/week (Intensive sprint mode).
4. **Primary Milestone Goal**:
   - `bcyber_2027_admission`: Focus squarely on cracking the 2027 shortlist and hackathon.
   - `iit_research_internship`: Secure winter/summer research internship at IIT Kanpur (C3iHub) or IIT Madras.
   - `career_foundation`: Build genuine cybersecurity skills for hackathon wins and high-ticket off-campus placements.

---

### Stage 2: Gap Analysis Engine
Deterministic evaluation of the distance between their **Current Baseline** and their **Target Outcome**:

| Baseline × Profile | Identified Critical Gap | Strategic Imperative |
|---|---|---|
| `class_12_jee` + `total_zero` | Severe risk of blowing JEE prep if overcomplicating cyber. | **Protection Rule**: 85% time to JEE Main (math/physics priority), 15% weekend hands-on lab. |
| `college_year_1` + `basic_c_math` | Strong algorithmic head, zero public proof-of-work, no CTF vocabulary. | **Leverage Rule**: Connect C & Maths to basic Cryptography & Networking; ship first public repo in 21 days. |
| `college_year_2_3` + `python_scripter` | Missing faculty-grade outreach and research-oriented project depth. | **Fast-Track Rule**: Build 1 protocol analyzer tool + direct cold-outreach dossier to C3iHub principal investigators. |

### Stage 3: Personal Path (Deterministic Execution Engine)
Deterministic routing matrix mapping combinations to structured 4-phase roadmaps:

#### Example Pathway: `Pathway-Alpha` (Class 12th JEE Aspirant, 5 hrs/week)
- **Phase 1 (Weeks 1–3)**: *Terminal & Linux Sanity* — OverTheWire Bandit 1–10 (1 hr/Sat, 1 hr/Sun).
- **Phase 2 (Weeks 4–6)**: *Networking Core* — Wireshark fundamentals; inspecting HTTP vs HTTPS traffic.
- **Phase 3 (Weeks 7–9)**: *CTF Primer* — PicoCTF beginner general skills & cryptography basics.
- **Phase 4 (Weeks 10–12)**: *Evidence Dossier Curation* — Compiling notes into a clean GitHub repository + optional 2-minute screen recording.

#### Example Pathway: `Pathway-Beta` (1st Year College with C & Math, 10 hrs/week)
- **Phase 1 (Weeks 1–2)**: *C to Systems Transition* — Memory models, pointers in security context, Linux GCC compilation.
- **Phase 2 (Weeks 3–5)**: *Network & Crypto Labs* — Socket programming in C, Caesar/XOR/RSA mathematical implementations.
- **Phase 3 (Weeks 6–8)**: *CTF Flag-Hunting* — TryHackMe pre-security path + Bandit 1–20 complete.
- **Phase 4 (Weeks 9–12)**: *Hackathon Entry & Proof-of-Work* — Unstop beginner hackathons + published technical writeup.

---

### Stage 4: Pinpointed Resources
No endless reading lists. Exactly 1–2 verified free resources per active phase with:
- Exact URL.
- Recommended completion benchmark (e.g., *"Stop at Level 15; do not get stuck on Level 16+"*).
- Trap warning (e.g., *"Do not read entire documentation; complete only Rooms 1 to 4"*).

---

### Stage 5: Proof-of-Work Checklist
Student-owned evidence tracking where the student links their actual artifacts:
- [ ] **Artifact 1**: Personal GitHub repository created (with clean `README.md` documenting learning notes).
- [ ] **Artifact 2**: OverTheWire Bandit milestone reached (Level 10+ completed, personal notes recorded).
- [ ] **Artifact 3**: 1 Practical Mini-Writeup (Solving a sample challenge or analyzing a PCAP file).
- [ ] **Artifact 4 (Optional Video Edge)**: 2-minute unlisted YouTube screen recording walking through their terminal and code.

---

### Stage 6: Persistent In-Browser Tracker
- In-browser persistent state (localStorage / Zustand).
- Visual progress bar across active phases.
- Daily/Weekly single "Next Best Action" card to eliminate decision fatigue.
- Check-off actions that update live completion stats.

---

### Stage 7: Recovery Protocol ("When Life Hits")
When mock tests tank, college mid-terms arrive, or a student falls 2 weeks behind:
- **The "Pause Without Guilt" Mechanism**: One-click freeze of the timeline.
- **Emergency Minimum Viable Routine**: Drops requirements to 60 minutes/week to maintain momentum without stress.
- **Catch-up Triage**: Identifies which tasks can be safely skipped and which core milestones must be preserved.

---

### Stage 8: Recalibration Engine
When reality changes (e.g. JEE Main session 1 finishes, college vacations start, or weekly hours increase from 5 to 15):
- One-click profile adjustment.
- Re-sequences remaining milestones without erasing previous completed progress.
