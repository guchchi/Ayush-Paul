# AUTHORITY SYSTEM

Authority must come from evidence.

Never from claims.

Every section must contain proof.

Proof hierarchy:

Level 1

* Awards
* Competitions
* Certifications

Level 2

* Projects shipped
* Products launched
* Open-source releases

Level 3

* Students impacted
* Collaborations completed
* Sponsors supported

Level 4

* Testimonials
* Partner logos
* Success stories

Rule:

Never say:
"Building the future."

Instead show:

* Projects
* Metrics
* Outcomes
* Impact

Authority = Evidence × Visibility
