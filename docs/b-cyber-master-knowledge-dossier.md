### 5. The In-Person Hackathon (New Core Lab Blueprint)

In the inaugural selection, shortlisted candidates reported to IIT Kanpur for a **6-hour practical test** (10:00 AM – 4:00 PM) at the **New Core Lab**.

#### Hackathon Operational Specifications
- **Hardware/Software Environment**: Sanitized desktop workstations prepared and locked down by IIT Kanpur technical staff. No personal laptops or unauthorized external communication permitted.
- **Monitoring**: Supervised continuously by IIT Kanpur faculty, technical staff, and C3iHub security engineers.
- **Logistics**: Mandatory reporting by 9:00 AM; entry gates locked at 9:45 AM. Working packed vegetarian lunch and drinking water provided at workstations.

#### The 8 Evaluated Technical Domains
1. **Cryptography**: Classical ciphers, modular arithmetic, XOR operations, AES/RSA implementation logic, entropy analysis.
2. **Web Security**: SQL Injection (SQLi), Cross-Site Scripting (XSS), Server-Side Request Forgery (SSRF), Insecure Direct Object References (IDOR), session hijacking.
3. **API Security**: Broken Object Level Authorization (BOLA), parameter tampering, JSON Web Token (JWT) manipulation, rate-limit bypassing.
4. **Network Security**: Packet capture (.pcap) analysis in Wireshark, TCP/IP handshakes, DNS anomalies, port scanning mechanics.
5. **Reverse Engineering**: Linux ELF / Windows PE binary inspection, disassembly analysis in GDB/Ghidra, string extraction, bypassing basic control-flow checks.
6. **OSINT (Open-Source Intelligence)**: Infrastructure reconnaissance, domain history forensics, public metadata correlation.
7. **Operating Systems (Linux & Windows)**: Linux shell fluency, file permissions, cron analysis, system calls, process monitoring, Windows registry/event log triage.
8. **Malware & Threat Analysis**: Static signature matching, string identification, unpacking heuristics, behavioral pattern recognition.

### 6. FAQ 22 Standards: Verifiable Proof-of-Work vs. Anti-Patterns

> **IIT Kanpur WSAIS FAQ 22**: *"This will include, but not limited to, reported vulnerabilities by candidates, cybersecurity projects/products developed by them, open-source contributions to cybersecurity projects, or other relevant accomplishments. The criticality and technical details of the vulnerabilities disclosed by them will be considered during the shortlisting. The candidate will have to provide easily verifiable evidence of the work done."*

#### The Proof-of-Work Evaluation Matrix

| Category | What Stands Out (High Signal) | What Gets Filtered Out (Anti-Patterns) |
| :--- | :--- | :--- |
| **Vulnerability Disclosures** | Documented responsible disclosures to NCIIPC, Bugcrowd, HackerOne, or academic bug bounties. Hall of Fame acknowledgments, technical CVE writeups explaining root-cause vulnerability logic. | Automated scanner dumps (e.g., missing SSL ciphers or X-Frame-Options headers), spamming website owners, unauthorized testing on private infrastructure. |
| **Original Tools & Utilities** | Clean GitHub/GitLab repositories with active commit histories. Code written in Python, C, or Go solving concrete network, crypto, or packet triage problems (e.g., custom ARP spoof detector, modular port scanner). Detailed README.md with test outputs. | Forking/cloning existing tools (like `sqlmap` or `nmap`) with trivial cosmetic README changes. Uploading full repositories in a single commit. |
| **Open-Source Contributions** | Merged Pull Requests in recognized cybersecurity tools, packet libraries, or wargame platforms. Verifiable code reviews and commit history. | Trivial single-character typo fixes to inflate commit counts. Submitting unmerged or rejected pull requests. |
| **CTF & Lab Problem Solving** | Methodical writeups of non-trivial challenges (PicoCTF, OverTheWire, HackTheBox, TryHackMe) explaining the underlying security concept, failed hypotheses, and network logs. | Copy-pasting public exploit flags without conceptual analysis. Listing flag strings without problem-solving methodology. |
| **Certifications & Courses** | Academic rigor, ranked competitive CTF standings, verifiable open-source artifacts. | Submitting generic paid video course completion certificates (Coursera, Udemy, local coaching institutes) without reproducible code. |

### Point-by-Point UI/UX Design Specifications

#### 1. Institutional Identity & Trust Badging
- **User Need**: Aspirants need instant confirmation that this is an authentic IIT undergraduate degree, not a continuing education diploma or online certificate.
- **UI Pattern**:
  - Top institutional badge bar featuring IIT Kanpur WSAIS and IIT Madras co-branding.
  - Three distinct semantic trust badges:
    1. `Official Institute Fact` (Emerald badge — backed by Senate ordinances and official portal).
    2. `Observed 2026 Precedent` (Sky blue badge — historical 2026 shortlisting rules, non-binding for 2027).
    3. `Pending Official Notice` (Amber badge — upcoming 2027 entrance test dates/syllabus).
  - Every factual claim has an inspectable **Source Citation Drawer** showing verbatim quotes, URLs, and PDF links.

#### 2. The 2026 vs 2027 Admission Paradigm Shift
- **User Need**: Clear guidance on whether they should study for JEE Main or focus on cybersecurity and the upcoming entrance test.
- **UI Pattern**:
  - Side-by-side comparative card with dark glassmorphism styling.
  - Left Side: *2026 Inaugural Cycle* (JEE Main + Prior Work shortlisting -> 6h Hackathon).
  - Right Side: *2027 Future Cycle* (FAQ 23: JEE Main discontinued -> Separate Entrance Test + Hackathon).
  - Prominent alert box debunking rumors of unverified "leaked syllabi" and directing students to foundational mathematics and computing logic.

#### 3. Interactive 30-Second Eligibility Screener
- **User Need**: Instant clarity on complex eligibility nuances (age limits, JoSAA 2025 concurrent admission restrictions, NIOS validity).
- **UI Pattern**:
  - Interactive questionnaire widget:
    - Q1: Academic Stream (Class 12 PCM with 5 subjects vs other).
    - Q2: Date of Birth (Calendar picker validating against Oct 1, 2001 or Oct 1, 1996 for reserved categories).
    - Q3: Category (General, OBC-NCL, EWS, SC, ST, PwD).
    - Q4: JoSAA 2025 History (Admitted to IIT vs Withdrew before final round vs Never reported).
    - Q5: Nationality (Indian National vs Other).
  - Immediate result display: "Fully Eligible" or "Specific Ineligibility Flag" with the exact ordinance citation.

#### 4. The 2+2 Curriculum & Credit Visualizer
- **User Need**: Understanding what they will actually study during the 2 years on campus and where they will work during the 2 years of internship.
- **UI Pattern**:
  - Two-stage visual progress stepper:
    - Stage A: *Years 1 & 2 (Foundations & Lab Specializations)* — 4 semester tabs with course lists, credit weights, and lab badges.
    - Stage B: *Years 3 & 4 (Field Deployment)* — Govt organization deployment, 54 credits/semester, stipend information, and regular IIT student status.
  - Interactive "Exit Options" card showing Certificate (150 Cr) and Diploma (200 Cr) pathways.

#### 5. Hackathon Blueprint & 8 Evaluation Pillars
- **User Need**: Transparency into what happens inside the New Core Lab during the 6-hour hands-on test.
- **UI Pattern**:
  - Interactive 8-card grid representing the technical domains (Crypto, Web, API, Networks, Reversing, OSINT, OS, Malware).
  - Clicking any card expands a drawer detailing:
    - Core concepts evaluated.
    - Sample challenge archetype.
    - Terminal tools required (GDB, Wireshark, Burp, CyberChef).
    - Common stumbling blocks.

#### 6. FAQ 22 Proof-of-Work Standards Matrix
- **User Need**: Knowing exactly what to include in their portfolio to avoid getting rejected.
- **UI Pattern**:
  - Split comparison view:
    - Green Column: **What Committee Approves** (Reproducible Git commits, responsible bug disclosures, detailed CTF writeups).
    - Red Column: **What Gets Rejected** (Generic Udemy certificates, scanner spam, cloned repositories).
  - Downloadable/copyable markdown templates for a verifiable project README and CTF writeup.

#### 7. Official Verbatim FAQ Directory (FAQs 1–26)
- **User Need**: Access to all official institute answers in one place, searchable and categorized.
- **UI Pattern**:
  - Filter chips: `All`, `Admissions & Tests`, `Curriculum & Labs`, `Fees & Hostels`, `Placements & Careers`.
  - Live keyword search bar.
  - Each accordion item displays the question, official verbatim answer, source anchor tag, and relevant policy context.
