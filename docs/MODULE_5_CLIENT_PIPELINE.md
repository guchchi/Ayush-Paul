# Module 5: Client Pipeline System — Deep Dive

## Architecture Overview
Module 5 operates on `useClientPipelineStore`.

### Pipeline Stages
1. **Identified**: Qualified opportunities.
2. **Contacted**: Outreach active.
3. **Engaged**: Discovery completed.
4. **Proposal Sent**: Offer & deliverables presented.
5. **Closed Won**: Agreement executed.

### Features
- Kanban view with drag-and-drop stage updates.
- Proposal readiness checklist.
