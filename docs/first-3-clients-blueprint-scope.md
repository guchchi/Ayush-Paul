# Blueprint Master Specification v1.0

---

## Product Name

**Client Acquisition System**

## Product Category

**Execution Blueprint**

Not a course. Not coaching. Not freelancing services. A professional operating system for acquiring, closing, and serving clients.

## Core Promise

Help freelancers build a professional client acquisition and delivery system that enables them to position themselves correctly, create irresistible offers, build authority, find prospects, start conversations, close deals, and deliver professionally — without wasting time on unnecessary theory.

---

## Target Audience

### Primary
- Video Editors
- Designers
- Developers

### Future Expansion
- Writers, Teachers, Marketers

---

## Architecture

```text
Phase 1 — Opportunity Mapping        → Opportunity Profile
Phase 2 — Offer Engineering System   → Professional Offer Sheet
Phase 3 — Authority System           → Portfolio + Authority Assets + Professional Profile
Phase 4 — Client Pipeline System     → Lead Tracker + Pipeline Dashboard + Prospecting Workflow
Phase 5 — Outreach Engine            → Outreach System + Message Library + Follow-Up Engine
Phase 6 — Client Conversion System   → Proposal + Pricing System + Onboarding System
Phase 7 — Delivery & Growth System   → Delivery SOP + Testimonial System + Referral System
```

## Production System

Located at `src/data/blueprint-production/`:

| Path | Purpose |
|------|---------|
| `framework.json` | Master framework — all 7 phases with mission brief, execution steps, track variations |
| `tracks.json` | Career track definitions with platforms, services, pricing, signals, tools |
| `templates/` | Downloadable assets (offer generator, outreach pack, proposal, tracker) |
| `prompts/` | AI prompt library — 1-3 per phase |
| `examples/` | Good/bad examples per track |
| `checklists/` | Completion checklists per phase |
| `video-scripts/` | Scripts for each phase video |
