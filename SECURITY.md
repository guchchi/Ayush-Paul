# Security Policy

## Vulnerability Disclosure

If you think you have found a security vulnerability in this project, please report it to our engineering team rather than opening a public issue on GitHub. 

You can report vulnerabilities privately by emailing:
`responsible-disclosure@ayushpaul.in` (Placeholder contact)

Please include:
- A description of the issue.
- Step-by-step instructions to reproduce it.
- Any potential impact.

We will acknowledge receipt within 48 hours and work to patch the issue as quickly as possible.

## Out of Scope
The following testing methods are strictly prohibited and out of scope:
- Denial of Service (DoS/DDoS) testing.
- Physical attacks against servers or data centers.
- Social engineering (phishing, vishing, etc.) of users, staff, or contractors.
- Spamming or automated form submissions.

## Educational & Portfolio Disclaimer
This repository contains research blueprints, code templates, and developer educational resources. The security controls implemented within this codebase represent best-effort configurations designed to prevent common architectural and payment bypass vectors.
